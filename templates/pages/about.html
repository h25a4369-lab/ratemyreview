A simple idea: the best guide to a place is someone who has actually been there.

Why we built this

Choosing where to eat, stay or spend an afternoon usually means guessing. Reviews are scattered across social media, maps and messaging groups, and it is hard to tell which ones are useful. Rate My Review brings those opinions into one calm, readable place.

Anyone can browse places and read reviews without an account. If you want to add your own experience, you create a free account, pick the place, choose a rating from one to five stars and write a few honest sentences.

What you can do here

  • Search places by name, location or category.
  • See an average rating calculated from every saved review.
  • Read reviews sorted by newest, highest or lowest rating.
  • Write, edit and delete your own reviews.
  • Report content that looks like spam or abuse for a human to check.

How ratings work

Every review carries a whole-star rating from 1 to 5. The average shown on a place is simply the sum of the saved ratings divided by the number of reviews, rounded to one decimal place. One person can leave one review per place; you can edit it later instead of posting again, so a single visit cannot be counted twice.

About this build

Rate My Review is a university project demonstration. It runs on a Python FastAPI backend with a SQLite database and server-rendered HTML, CSS and JavaScript. The places and reviews you see on first launch are clearly labelled sample data so the site is not empty, and administrators can add, edit or remove places at any time.
